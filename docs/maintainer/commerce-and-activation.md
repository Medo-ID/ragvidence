# Retired commerce and activation proposal

The earlier Free/Plus and payment-activation proposal is retired. Do not implement
entitlement checks, receipts, license servers or checkout gates for the CLI.
Version 0.2.0 is completely free under Apache-2.0. Website donations/sponsorship
are voluntary, with user-chosen amounts and no features unlocked.

The website is a separate project and will be updated in its own session using
root `instructions.md`. No donation destination has been selected here.
