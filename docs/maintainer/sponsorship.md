# Optional sponsorship setup

Sponsorship is not configured. All CLI features are free. Stars, bug reports,
documentation and code contributions are welcome ways to support the project.
Financial setup can be completed independently of the release.

## Set up GitHub Sponsors later

1. Visit https://github.com/sponsors and choose **Get sponsored** for **Medo-ID**.
2. Follow the profile, contact, payout/bank and tax-information steps, enable 2FA,
   and request GitHub approval. Complete financial/identity details in GitHub's
   own interface, not in this repository or chat.
3. In the Sponsors dashboard, open **Sponsor tiers** and configure **Custom amounts**.
   Sponsors can choose their amount; fixed one-time/monthly tiers are optional.
   Keep any recommended/minimum amounts consistent with the voluntary support model.
4. Once the profile is approved and live, verify its actual public URL, then add
   `.github/FUNDING.yml` on main with:

```yaml
github: Medo-ID
```

5. Enable the repository's **Settings → General → Features → Sponsorships** option
   if needed. Use the same verified URL for the website's optional Sponsor button
   in its separate update session. Test the link without initiating a payment.

GitHub currently lists Morocco among supported receiving regions; account
eligibility and onboarding still follow the current GitHub process. An alternative
funding service can be used later if the maintainer chooses an actual supported
public URL. Never fabricate an account/link or claim charitable tax deductibility.
