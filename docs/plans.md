# Free CLI and voluntary support

From version 0.2.0, RAGvidence has one completely free CLI under
[Apache-2.0](../LICENSE.md). All included capabilities are available without
activation, an account or payment. There is no Plus edition or paid feature gate.

Optional donations or sponsorship support the maintainer. Users choose whether
to contribute and the amount; contributions do not unlock features or purchase a
support response guarantee. A support link may be added to the website separately.

Third-party API usage, model downloads, hardware and hosting remain the user's
responsibility. RAGvidence does not provide API credits or guarantee retrieval or
answer quality. Third-party code and models keep their own licenses.

The historical 0.1.0 release was published under its earlier proprietary terms.
The new license declaration does not relabel that artifact or the separate website.
