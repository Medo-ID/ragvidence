# Orion DeskHub

## Firmware 4.2 — Pairing reset

Hold the pairing button for eight seconds. Release it after two amber flashes.
The reset clears Bluetooth pairing but preserves display settings.

## Firmware 4.1 — Pairing reset

Hold the pairing button for five seconds. Release it when the ring turns blue.

## Power

Connect the hub to a USB-C power supply. Wait for a steady white light before use.
